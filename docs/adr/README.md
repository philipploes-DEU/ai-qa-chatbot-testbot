# Architekturentscheidungen

Jede Datei hier hält eine Entscheidung fest: Kontext, Entscheidung, Begründung und Konsequenzen.
Neue Entscheidungen bekommen die nächste freie Nummer, überholte bleiben stehen und verweisen auf
ihre Nachfolger.

Issue-Nummern wie `#74` beziehen sich auf das private Entwicklungs-Repository von AI QA. Das
öffentliche Release-Repository hat eigene Issues, dort führen solche Verweise nicht zum
beschriebenen Thema ([ADR 0023](0023-oeffentliches-release-repository.md)).
